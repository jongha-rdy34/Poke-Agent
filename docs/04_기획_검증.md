## 2. Tool 설계 확인 — 실제 응답을 출력 구조에 맞춰 본 결과

| 확인 항목 | 결과 | 설계 반영 |
|---|---|---|
| 판단 속성이 응답에 있는가 | PokeAPI: types, stats.speed, abilities ✅ / Smogon: Moves·Items·Spreads 가중치 ✅ / Showdown: type, category, basePower, priority ✅ | 그대로 사용 |
| **이름 규칙 불일치** | Smogon `Mimikyu`, `Indeedee`, `Basculegion` → PokeAPI는 `mimikyu-disguised`, `indeedee-male`, `basculegion-male`만 존재 (404) | `/pokemon-species/{name}`의 기본 폼으로 보정 + notes에 기록 |
| **값이 비어 오는 경우** | Champions 포맷의 `Tera Types`는 전부 `"nothing"` | 테라 항목은 빈 배열로 반환 (임의 값 금지) |
| **포맷별 능력치 체계 차이** | Champions 포맷 Spreads가 `Jolly:2/32/0/0/0/32` — 노력치가 아니라 SP(최대 32) | 필드명을 `points`로 두고 F3025★(포맷별 계산식 분리) 추가 |
| 비율 계산 기준 | 기술 가중치 합은 4배가 되므로, 포켓몬당 하나인 **특성 가중치 합**을 분모로 사용 (한카 지진 98.8%) | `_pct_table(total=sum(Abilities))` |
| 레이팅 컷이 포맷마다 다름 | gen9ou: 0/1500/1695/1825, Champions: 0/1500/1630/1760 | 요청 컷이 없으면 가장 가까운 컷 + notes |
| 미래 월 요청 | `/stats/2099-01/...` → 404 | 최근 집계월로 조회, `estimated:true` |
| `typechart.json` 없음 | `typechart.json` 404, `typechart.js`(JS 객체)만 제공 | JS → JSON 변환해 파싱, 실패 시 UPSTREAM_ERROR |
| 신규 폼 커버리지 | `garchomp-mega-z`, `golisopod-mega` PokeAPI에 존재 ✅ | — |

### 호출 한도와 이용 조건
- PokeAPI: 공정 이용 정책상 로컬 캐시 권장 → 7일 디스크 캐시, 한국어 이름은 1회 수집(포켓몬 1025 + 기술 937 요청, 동시 8개).
- Smogon: 약관 명시 없음, 파일이 큼(OU 12MB) → 30일 캐시.
- Showdown: 약관 명시 없음, MIT 소스 → 24시간 캐시.
